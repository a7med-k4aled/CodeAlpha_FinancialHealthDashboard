# 📊 Financial Health Dashboard

**Power BI Internship Project — CodeAlpha**





## 📌 Project Overview

The Financial Health Dashboard is an interactive Power BI project developed as part of the CodeAlpha Power BI Internship.

The project transforms raw sales and financial data into meaningful insights through data cleaning, modeling, DAX calculations, financial analysis, business performance analysis, and interactive visualizations.

## 🎯 Project Objective

Analyze business and financial data to understand:

- Revenue and profitability
- Financial health and performance
- Cash flow
- Customer and product performance
- Regional performance
- Future revenue and profit trends

## 🗂️ Dataset

- **Format:** CSV
- **Records:** 200,000+ 
- **Main Data:** Orders, customers, products, sales, revenue, and profit

### Main Columns

- Order_ID
- Order_Date
- Customer_Name
- City
- State
- Region
- Country
- Category
- Sub_Category
- Product_Name
- Quantity
- Unit_Price
- Revenue
- Profit

## 🧹 Data Cleaning & Transformation

Data preparation was performed using **Power Query**.

Main steps included:

- Changed data types
- Removed customer name titles
- Trimmed text values
- Removed customer name suffixes
- Cleaned text values
- Created a Gender column
- Prepared the data for analysis and modeling

## 💡 Key Insights

- Electronics is the highest-performing category in revenue and profit.
- Overall profit margin is **14.23%**.
- Current Ratio is **1.28**.
- ROE is **36.67%**.
- The top 10 customers contribute around **30% of total revenue**.
- The top 10 products contribute around **40% of total revenue**.
- The West region has the highest performance.
- The South region has the lowest performance.
- Operating cash flow is positive.
- Forecast revenue is approximately **10% higher**.
